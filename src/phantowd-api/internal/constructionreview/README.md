# Constructor rollback classification

Internal trusted-constructor utility, not ownership or execution authority.
Opaque domain errors embed Marker while retaining their failed lifetime.
Contains follows error wrapping; a plain review sentinel does not qualify.
Rollback preserves the original cause after verified cleanup. Nested retained
errors, missing cleanup or failed cleanup require the caller to retain an opaque
handle and remaining inputs. Existing constructors are not retrofitted by this
package. No recovery, retry, I/O or process operation is supplied.

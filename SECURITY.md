# Security policy

PhantoWD EX4 is pre-release research and must not be treated as production
firmware. There are currently no supported releases.

Do not open a public issue containing credentials, private keys, LAN topology,
raw flash contents, or proprietary WD firmware. Report a security issue
privately to the repository owner once a private reporting channel is
configured.

Future update support must require signed manifests and signed, model-specific
artifacts. Public verification keys may be embedded in firmware; private
signing keys must never be stored in this repository or ordinary CI artifacts.
